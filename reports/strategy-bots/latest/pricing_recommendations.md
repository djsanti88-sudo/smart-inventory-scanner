# PricingAdvisorBot — pricing recommendations

Anchored to public competitor pricing (competition_report.md): Sortly $49 / $149 / $299, Zoho $39–$299,
inFlow $186–$999. SIS is a **niche accuracy** tool, not an ERP — price on outcome (right product, fast
count) and tire/auto fit, keep tiers simple enough for a shop owner to grasp in 10 seconds.

## Recommended tiers (simple)
| tier | price | for | includes |
|------|-------|-----|----------|
| **Free trial / Pilot starter** | $0 for 14 days (or 1 location, capped items) | try it | scan, count, dedupe, CSV export, 1 user |
| **Shop Basic** | **$99/mo** | single shop | everything in core: multi-code scan, mismatch guard, Needs Review, CSV import/export, up to ~3 users, offline |
| **Shop Pro** | **$199/mo** | busy shop / manager | Basic + enforced roles, scan logs + employee accountability, audit history, low-stock/stock targets, vendor templates, more users |
| **Multi-site** | **$399/mo** | 2–5 locations | Pro + multi-location rollups, advanced exports |
| **Enterprise** | **$499+/mo (custom)** | chains / integrators | Multi-site + API/Shop-Ware/QuickBooks integration, SSO, dedicated onboarding |

## Answers
1. **First paid pilot cost?** **$99/mo with a $199 one-time white-glove setup** (you import their products
   + train staff). The setup fee filters tire-kickers and funds your time; waive it for the very first 1–2 design-partner shops.
2. **Setup fee?** Yes — one-time $199 (Basic/Pro), higher for Multi-site/Enterprise. It's where real
   onboarding value (import + alias seeding) lives.
3. **$99 plan includes?** All core counting + multi-code accuracy + mismatch guard + CSV in/out + offline + a few users. The whole "right product, fast count" promise.
4. **$199 plan includes?** Manager layer: enforced roles, who-scanned-what, audit history, low-stock/stock
   targets, vendor templates. This is the retention tier.
5. **What justifies $499?** Multi-location + integrations (Shop-Ware/QuickBooks/API) + SSO + dedicated
   onboarding — i.e., the things chains and integrators need; still far below inFlow Mid-Size ($999).
6. **Add-ons?** Tire catalog enrichment (premium), part-number-only import + enrichment, bulk CSV cleanup
   service, extra locations, API connectors. Bill monthly except cleanup (one-time).
7. **Not free?** Multi-code/enrichment at scale, manager reports, role enforcement, integrations, the code library.
8. **Stay free/basic (reduce friction)?** Single-user scan + count + CSV export, capped items. Let them feel
   the accuracy before paying. (Mirrors Sortly's free funnel.)
9. **First 10 shops pay?** Discounted design-partner deal: **$49–$99/mo, setup waived**, in exchange for a
   testimonial + feedback. Lock the rate for 12 months.
10. **First 100 shops pay?** Standard **$99 Basic / $199 Pro**, $199 setup. Annual = ~2 months free.
11. **Simple enough?** Yes — two everyday tiers ($99 / $199) + one growth tier. Avoid per-item or per-scan
    metering at the shop level (confusing); meter only enterprise/API.

## Guardrails
- Don't undercut to Sortly's $49 — you'll attract price-shoppers and can't fund onboarding. Win on accuracy + niche, not price.
- Keep the **protected code DB** off every customer-facing plan as a *feature* — it's the moat, not a SKU.
