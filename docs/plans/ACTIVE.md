# Active plan

There is currently no owner-approved executable plan in `docs/plans/`.

Use `PROGRESS.md` for the current phase and next owner-gated actions. A plan becomes active only when
the owner explicitly approves its exact path and revision. Filename dates, draft status, prior
approval of a different plan, or being the newest file never grants authority.

When a plan is approved, replace this statement with one relative link, the approved revision or
commit, approval date, scope, and completion gate. When the plan closes or is superseded, return this
file to the explicit no-active-plan state and promote durable decisions into canonical docs.
