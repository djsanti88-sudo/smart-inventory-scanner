Read-only analysis pass. Zero edits made. Scope per brief: `scripts/`, `docs/`,
`package.json` scripts, `.gitignore` coverage, root-level stray files, test-file sprawl.
Baseline: `npm run proof:local` green (4124 passed / 105 skipped) at time of analysis.

Method: for every "dead" claim, `rg -l --fixed-strings "<basename>"` across the repo
(excluding `.next/`, `node_modules/`) minus the file's own self-reference, cross-checked
against `package.json` scripts, `vitest.config.ts` includes/excludes, `.github/workflows/`,
and doc references. Zero-hit results were individually opened to rule out invocation via
flag/env/loader that a filename grep would miss (e.g. `node --loader`).
